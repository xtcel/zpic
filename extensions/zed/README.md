# zpic Assistant for Zed

This Zed extension adds a small set of Assistant slash commands that invoke a
locally installed `zpic` binary:

- `/zpic-upload`
- `/zpic-doctor`
- `/zpic-history`
- `/zpic-uploader-list`

The extension intentionally stays thin. Daily editor workflow should use the
project-local tasks generated by:

```bash
zpic zed init
```

Those tasks handle clipboard upload, current-file migration, and optional
keybindings inside any content project.

## Local development

1. Install `zpic` so it is available on your shell `PATH`.
2. In Zed, run `zed: install dev extension`.
3. Select this `extensions/zed` directory.
4. Open the Assistant and run `/zpic-doctor`.

If Zed cannot find `zpic`, restart it from a shell where `zpic` is already on
your `PATH`.
